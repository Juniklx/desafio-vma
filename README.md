# 🔀 Desafio VMA — Versionamento e Metodologia Ágil

Desafio individual que une **versionamento com Git/GitHub** à metodologia ágil **SCRUM**, simulando o site de uma concessionária Ford com listagem de veículos e página de contato.

## 🎯 Objetivo do desafio

- Criar um repositório remoto no GitHub
- Subir os arquivos `index.html` e `contato.html`
- Criar as branches `index` e `contato` para implementar as histórias de usuário 1 e 3
- Fazer o merge de cada branch com a `main` e o push para o repositório remoto
- Gerar e disponibilizar os documentos de **Sprint Backlog** e **Sprint Retrospective**

## 📁 Estrutura do projeto

```
desafio-vma/
├── index.html                 # Página principal — lista de veículos
├── contato.html                # Página de navegação/contato
├── Sprint_Backlog.pdf           # Documento de planejamento da sprint
└── Sprint_Retrospective.pdf      # Documento de retrospectiva da sprint
```

## 🚗 Conteúdo

**`index.html`** — lista de veículos em oferta:
- Ranger
- Territory
- Bronco Sport
- Mustang Mach 1

**`contato.html`** — menu de navegação entre as páginas do site (Principal, Veículos em oferta, Como falar conosco).

## 🌿 Fluxo de versionamento (Git Flow do desafio)

1. Criação do repositório remoto no GitHub
2. Branch `index` → implementação da página principal (história de usuário 1)
3. Branch `contato` → implementação da página de contato (história de usuário 3)
4. Merge de cada branch com a `main`
5. Push das alterações para o repositório remoto

## 📋 Artefatos SCRUM

- [`Sprint_Backlog.pdf`](./Sprint_Backlog.pdf) — planejamento das tarefas da sprint
- [`Sprint_Retrospective.pdf`](./Sprint_Retrospective.pdf) — retrospectiva do processo e aprendizados

## 🛠️ Tecnologias

- **HTML5**
- **Git** e **GitHub** (versionamento e branches)
- **SCRUM** (metodologia ágil)
